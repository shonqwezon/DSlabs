# Лабораторная работа номер 1

## Подготовка к работе

> Работа выполнена на Macbook Air M5 16 RAM / 512 GB / 10 CORES.

1. Инициализируйте python окружение
```
make bootstrap
```

2. Проверьте, что установлен gcc
```
gcc --version
```

## Проверка

1. Перейдите в нужную директорию и запустите `make`

```
cd 01_mandelbrot
make
```

2. Для запуска тестирования выполните `make test`.

В каждом `main.c` в шапке будут показаны мои результаты тестирования.

> **Важно!** Для запуска тестов второй задачи `02_nbodies` необходимо сгенерировать "сложные" данные с помощью `make generate`, на которых будет заметно преимущество многопоточной реализации. По умолчанию используется конфигурация красивого теста из `input2.txt` -> `input.txt`

## Примечания

- В `Makefile` к каждой задаче можно увидеть параметры для модификации запуска.
- Для MacOS отсутствует реализация `pthread_barrier_t` в системных библиотеках, поэтому используется [опенсорсный аналог](https://github.com/isotes/pthread-barrier-macos).
